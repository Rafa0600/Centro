📲 Mandar el PDF directo desde WhatsApp (iPhone)
Se arma una sola vez (app Atajos del iPhone):
  1. Atajos → + (nuevo atajo). Arriba, nombre: Centro.
  2. Tocá ⓘ (o la flechita del nombre) → activá Mostrar en hoja para compartir. Arriba donde dice "Recibir Cualquiera", dejá solo PDF / Archivos.
  3. Agregá la acción Obtener contenido de URL:
    • URL:
    • Tocá la flechita → Método: POST · Cuerpo de la solicitud: Archivo → Archivo: Entrada del atajo.
  4. Agregá la acción Mostrar notificación con el Contenido de la URL (dice "Listo: PDF enviado…").
Cada vez: en WhatsApp abrís el PDF → botón compartir ⬆ → Centro. Después abrís esta app y te pregunta si confirmás.
